# Constrained Nonlinear Control through Driftless Approximation

This is the project website accompanying the paper ["Ignore Drift, Embrace Simplicity: Constrained Nonlinear Control through Driftless Approximation"](https://arxiv.org/abs/2509.06188), a.k.a. _Driftlessification_. This website contains additional illustrations that are not present in the online version of the paper, demonstrating the performance of this technique.

The repository [Constrained-NL-Control](https://github.com/ram-p/Constrained-NL-Control) contains a simple code accompanying this project.

(Fun fact: the word _driftlessification_ doesn't appear anywhere in the paper.)
